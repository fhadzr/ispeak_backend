# INDONESIAN L1 ERRORS IN ENGLISH — COMPLETE REFERENCE (RAG VERSION)

## OVERVIEW
Error umum terjadi karena:
- Transfer dari Bahasa Indonesia (tidak ada tense, article, plural wajib)
- Perbedaan sistem fonetik Indonesia vs Inggris
- Kurangnya exposure pada native English prosody
- Overgeneralization grammar rules

# BAGIAN 1: GRAMMAR ERRORS (MORPHOLOGICAL & SYNTACTIC)

## 1.1 MORPHOLOGICAL ERRORS

### Verb Form Errors
Problem: Salah pakai V1, V2, V3, atau tambahan -s/-ed
```
❌ may represents → ✅ may represent
❌ will analyzes  → ✅ will analyze
❌ to following   → ✅ to follow
❌ are avoid      → ✅ are avoiding
```

### Possessive ('s)
```
❌ the speaker right → ✅ the speaker's right
❌ my friend house   → ✅ my friend's house
```

### Past Participle
```
❌ article use       → ✅ article used
❌ Did you studied?  → ✅ Did you study?
❌ is promote        → ✅ is promoted
```

### Adverb (-ly)
```
❌ general different → ✅ generally different
❌ she speak slow    → ✅ she speaks slowly
```

## 1.2 SYNTACTIC ERRORS

### Article Errors (a, an, the)
Root cause: Bahasa Indonesia tidak memiliki artikel
```
❌ using Chinese film     → ✅ using a Chinese film
❌ I want buy book        → ✅ I want to buy a book
❌ She is teacher         → ✅ She is a teacher
❌ in the chapter five    → ✅ in chapter five
❌ The life is beautiful  → ✅ Life is beautiful
```

### Plural / Singular
```
❌ two language     → ✅ two languages
❌ another tables   → ✅ another table
❌ many information → ✅ much information
❌ three student    → ✅ three students
```

### Subject-Verb Agreement
```
❌ she go    → ✅ she goes
❌ they is   → ✅ they are
❌ he study  → ✅ he studies
❌ she have  → ✅ she has
```

### Tense Errors
```
Past:
❌ Yesterday I go to school      → ✅ Yesterday I went to school
❌ She observe the experiment    → ✅ She observed the experiment

Present Perfect:
❌ I already go there            → ✅ I have already gone there
❌ they had translated (wrong)   → ✅ they have translated

Future:
❌ I will going tomorrow         → ✅ I will go tomorrow
```

### Preposition Errors
```
❌ respond the compliment → ✅ respond to the compliment
❌ focus to               → ✅ focus on
❌ interested for         → ✅ interested in
❌ married with           → ✅ married to
❌ arrive to the airport  → ✅ arrive at the airport
❌ depend from            → ✅ depend on
```

### Passive Voice
```
❌ is promote              → ✅ is promoted
❌ has been recording      → ✅ has been recorded
❌ the project is complete → ✅ the project is completed
❌ was build               → ✅ was built
```

# BAGIAN 2: PRONUNCIATION ERRORS (PHONEMIC)

## 2.1 CONSONANT SUBSTITUTIONS

### /v/ → /f/ atau /b/ Substitution
Root cause: Bahasa Indonesia tidak memiliki fonem /v/ (frikatif labiodental bersuara)
```
Target → Typical production:
very    → fery / bery
have    → hafe / habe
love    → lof / lob
vote    → fote
vine    → fine
```

Remediation exercises:
1. Minimal pair drills: vine/fine, vat/fat, vest/fest, veil/fail, vote/note
2. Lip placement: upper teeth harus menyentuh lower lip, kemudian vibrasi
3. Shadowing: record native speaker mengucapkan /v/ words, tirukan langsung
4. Tongue twisters: "Vivid violets varied very vigorously"
5. Sentence practice: "Victor visited Venice in November"
Estimated improvement: 5–8 sessions of 15 minutes

---

### /θ/ → /d/ atau /t/ Substitution (Voiceless TH)
Root cause: Tidak ada dental fricative dalam Bahasa Indonesia
```
Target → Typical production:
think   → dink / tink
three   → dree / tree
bath    → bat / bad
thin    → din / tin
thanks  → danks / tanks
```

Remediation exercises:
1. Tongue placement: ujung lidah di antara gigi atas dan bawah
2. Airflow practice: tiupkan udara melewati lidah yang dijepit gigi
3. Minimal pairs: think/dink, thin/din, three/tree, bath/bad
4. Mirror practice: pastikan lidah terlihat di antara gigi
5. Sentence drills: "Think about three things thoroughly"
Estimated improvement: 6–10 sessions

---

### /ð/ → /d/ Substitution (Voiced TH)
Root cause: Sama seperti /θ/ namun bersuara
```
Target → Typical production:
the     → de
this    → dis
that    → dat
mother  → moder
father  → fader
there   → dere
```

Remediation exercises:
1. Sama seperti /θ/ tapi tambahkan vibrasi pita suara
2. Practice: the/de, this/dis, that/dat, they/dey
3. Sentence: "The mother and father are there together"

---

### /z/ → /s/ Substitution
Root cause: /z/ ada di Indonesia tapi sering di-devoice
```
Target → Typical production:
zero    → sero
zoo     → soo
buzz    → bus
his     → hiss (devoiced)
was     → wass
```

Remediation:
1. Voiced vs voiceless contrast: /s/ vs /z/ — rasakan vibrasi di leher
2. Minimal pairs: zip/sip, zoo/sue, buzz/bus, prize/price
3. Sentence: "The zebra in the zoo is as big as a horse"

---

### Final Consonant Deletion
Root cause: Bahasa Indonesia adalah open-syllable language (suku kata terbuka)
```
Target → Typical production:
cat     → ca
bed     → be
book    → boo
class   → cla
stop    → sto
help    → hel
test    → tes
```

This is one of the MOST PERSISTENT errors for Indonesian speakers.
It affects comprehensibility significantly.

Remediation exercises:
1. Final consonant emphasis: hold final consonant for 1 full second
2. Word lists: cat/cap/cab/can/cam — feel each final sound
3. Sentence pairs: "I sit" vs "I sit down" — both must end clearly
4. Recording and self-monitoring: record yourself, listen back
5. Word-final /t/: "That, what, it, not, but, cut, put, sit, hit"
6. Word-final /d/: "Good, food, road, bed, head, red, said"
7. Word-final /k/: "Book, look, back, black, check, neck, pick"
8. Word-final /s/: "This, his, class, bus, bus, yes, dress"
Estimated improvement: 8–12 sessions (persistent pattern — needs daily practice)

---

### /æ/ → /e/ Substitution (Front Low Vowel)
Root cause: Bahasa Indonesia tidak memiliki fonem /æ/
```
Target → Typical production:
cat     → ket
bad     → bed
man     → men
black   → bleck
have    → hev
```

Remediation:
1. Jaw lowering: buka mulut lebih lebar dari biasa
2. Tongue position: depan, rendah, mulut lebih terbuka
3. Minimal pairs: cat/cut, bad/bed, man/men, black/bleck
4. Sentence: "The black cat sat on the mat"

---

### /ɪ/ → /i:/ Substitution (Short vs Long i)
Root cause: Bahasa Indonesia menggunakan /i/ panjang konsisten
```
Target → Typical production:
ship    → sheep
bit     → beat
sit     → seat
fill    → feel
it      → eat
```

Remediation:
1. Tension contrast: /ɪ/ = relaxed jaw, /i:/ = tense, smile wide
2. Minimal pairs: ship/sheep, bit/beat, sit/seat, fill/feel
3. Practice: "I'm sitting in this ship" — two /ɪ/ sounds

## 2.2 PROSODY & INTONATION ERRORS

### Flat Intonation Pattern
Root cause: Bahasa Indonesia menggunakan intonasi yang relatif datar
Effect: Speech sounds monotone, unnatural, dan kadang ambigu maknanya

```
Problem patterns:
- Statements end with rising tone (sounds like question)
- Questions sound like statements
- No pitch variation for emphasis
- Every word gets equal stress → unnatural rhythm
```

Remediation exercises:
1. Exaggerated intonation practice: baca dengan intonasi berlebihan dulu
2. Rising for questions: "Are you coming? ↑ Really? ↑ Why? ↑"
3. Falling for statements: "I went home. ↓ It was great. ↓"
4. Hand gesture technique: gerakkan tangan naik/turun sesuai pitch
5. Shadowing: tirukan native speaker recording (news, TED talks)
6. Sentence: "I LOVE it" (stress love) vs "I love IT" (stress it)

---

### Inappropriate Word Stress
Root cause: Bahasa Indonesia biasanya stress di suku kata ke-2 dari belakang (penultimate)
```
Common errors:
POlice    → should be poLICE
HOtel     → should be hoTEL
ENglish   → correct (this one is fine)
COMputer  → correct
reCORD (verb) → often said as REcord
conTENT (satisfied) → often confused with CONtent (material)
```

Remediation:
1. Stress marking drills: underline stressed syllable in wordlist
2. Noun vs verb stress pairs:
   - REcord (n) vs reCORD (v)
   - OBject (n) vs obJECT (v)
   - PREsent (n/adj) vs preSENT (v)
   - PROtest (n) vs proTEST (v)
3. Oxford 3000 stress pattern practice — focus on 2-syllable words

---

### Slow Speech Rate (Below B1 Threshold)
Indicators: WPM < 100 for B1+ speakers

Root causes:
- Real-time translation from Indonesian
- Insufficient vocabulary automaticity
- Low confidence leading to over-monitoring

```
Target speech rates:
A1:  < 80 WPM
A2:  80–100 WPM
B1:  100–120 WPM
B2:  120–140 WPM
C1:  140–160 WPM
C2:  150–180 WPM (native-like)
```

Remediation:
1. Timed speaking exercises: target 100 words in 60 seconds
2. Read-aloud progressively faster: same text, increase speed each round
3. Connected speech practice: reduce inter-word pauses
4. Automaticity drills: common phrases as chunks, not word-by-word
5. Shadowing: match native speaker's pace exactly

# BAGIAN 3: SPEAKING FILLER PATTERNS

## 3.1 Overuse of Fillers
Indonesian speakers often overuse fillers when thinking:
```
Common fillers:
- "uh", "um" (normal in moderation — problem if >3 per minute)
- "you know" (sometimes overused)
- "like" (informal overuse)
- Long silent pauses (>2 sec) replacing verbal fillers
```

## 3.2 False Starts
```
Pattern: Starting a sentence, stopping, restarting
Example: "I... I think that... I mean... the problem is..."
```

## 3.3 Remediation for Fillers
1. Replace silent pauses with breathing: inhale instead of "uh"
2. Practice: pause silently for 1 second when thinking (acceptable)
3. Prepare topic-specific vocabulary before speaking
4. Use discourse markers instead: "Well,", "Let me think,", "Actually,"

# BAGIAN 4: COHERENCE & COHESION ERRORS

## 4.1 Missing Discourse Markers
Indonesian students often connect ideas without cohesive devices:
```
❌ I like English. It is difficult. I study hard.
✅ I like English. However, it is difficult. Therefore, I study hard.

❌ She is smart. She failed the exam.
✅ Although she is smart, she failed the exam.

❌ He studied. He passed.
✅ Because he studied hard, he passed the exam.
```

## 4.2 Common Cohesive Devices to Practice
Adding information: furthermore, in addition, moreover, also
Contrasting: however, nevertheless, on the other hand, although
Cause-effect: therefore, consequently, as a result, because of this
Sequencing: first, then, next, finally, subsequently
Exemplifying: for example, for instance, such as, namely

# BAGIAN 5: ROOT CAUSES (UNTUK AI DIAGNOSTIC)

## Bahasa Indonesia vs English — Key Differences
```
Feature              | Bahasa Indonesia | English
---------------------|------------------|------------------
Tense markers        | None (pakai "sudah", "akan") | Mandatory (V2, will, have+V3)
Articles             | None             | a/an/the (mandatory)
Plural markers       | Reduplication optional | -s/-es (mandatory)
Verb conjugation     | None             | -s for 3rd person singular
Open syllable        | Yes (mostly)     | No (final consonants common)
Phoneme /v/          | Not present      | Common (very, have, love)
Phoneme /θ/ /ð/      | Not present      | Common (the, this, think)
Word stress pattern  | Penultimate default | Variable (meaning-changing)
```

## Transfer Error Examples
```
Indonesian → Incorrect English → Correct English
"Saya makan kemarin" → "I eat yesterday" → "I ate yesterday"
"Buku-buku" → "books books" → "books"
"Saya pergi ke sekolah setiap hari" → "I go to school every day" (correct!)
"Dia tidak datang" → "She not come" → "She doesn't come"
"Dua bahasa" → "two language" → "two languages"
```
