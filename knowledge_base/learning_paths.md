# CEFR-BASED LEARNING PATH (RAG VERSION)

## OVERVIEW
Learning path berbasis CEFR menggunakan:
- "Can Do" descriptors (apa yang bisa dilakukan learner)
- Task-based progression
- Kombinasi: communicative skill + language resource

Tujuan:
- Memberikan roadmap belajar adaptif
- Digunakan untuk feedback AI & rekomendasi belajar

---

# CORE STRUCTURE

Setiap level terdiri dari:

1. Communicative Tasks (Can Do)
2. Language Resources (Grammar + Vocabulary)
3. Practice Strategy
4. Assessment / Progress Check

---

# LEVEL LEARNING PATH

## A1 (BEGINNER)

### 🎯 Goal
Mampu komunikasi dasar dalam situasi sehari-hari

### 🧠 Can Do
- Introduce diri sendiri
- Tanya & jawab pertanyaan sederhana
- Gunakan angka, waktu, tanggal
- Memahami instruksi sederhana

### 🧩 Language Focus
- To be (am, is, are)
- Simple present
- Basic vocabulary (family, food, numbers)

### 🏋️ Practice
- Repetition speaking
- Listening simple dialogue
- Flashcard vocabulary

### 📊 Output
- Short sentences
- Basic conversation

---

## A2 (ELEMENTARY)

### 🎯 Goal
Mampu komunikasi sederhana dalam konteks familiar

### 🧠 Can Do
- Describe people, places, activities
- Talk about past events
- Express likes/dislikes
- Make simple plans

### 🧩 Language Focus
- Past simple
- Present continuous
- Going to (future)
- Comparatives

### 🏋️ Practice
- Role play (daily conversation)
- Short paragraph writing
- Listening instruction

### 📊 Output
- Simple paragraph
- Basic storytelling

---

## B1 (INTERMEDIATE)

### 🎯 Goal
Mampu komunikasi mandiri dalam berbagai situasi

### 🧠 Can Do
- Explain opinions
- Describe experiences
- Handle daily situations
- Give reasons & examples

### 🧩 Language Focus
- Present perfect
- First conditional
- Modal verbs (should, must)

### 🏋️ Practice
- Discussion
- Opinion speaking
- Structured writing

### 📊 Output
- Structured speech
- Opinion paragraph

---

## B2 (UPPER INTERMEDIATE)

### 🎯 Goal
Mampu komunikasi kompleks dan argumentatif

### 🧠 Can Do
- Debate
- Compare ideas
- Explain abstract topics
- Support argument

### 🧩 Language Focus
- Complex sentences
- Passive voice
- Linking words

### 🏋️ Practice
- Debate simulation
- Essay writing
- Listening lecture

### 📊 Output
- Argumentative speech
- Essay

---

## C1 (ADVANCED)

### 🎯 Goal
Mampu komunikasi efektif dan fleksibel

### 🧠 Can Do
- Express ideas fluently
- Adapt language to context
- Use idioms & nuance

### 🧩 Language Focus
- Advanced grammar
- Collocations
- Idiomatic expressions

### 🏋️ Practice
- Presentation
- Academic writing
- Critical discussion

### 📊 Output
- Fluent speech
- Academic essay

---

## C2 (PROFICIENT)

### 🎯 Goal
Near-native communication

### 🧠 Can Do
- Understand everything
- Express ideas precisely
- Handle complex discourse

### 🧩 Language Focus
- Natural language use
- Subtle meaning & tone

### 🏋️ Practice
- Real-world simulation
- Advanced discussion

### 📊 Output
- Native-like fluency

# ADAPTIVE LEARNING LOGIC (UNTUK AI)

## INPUT:
- CEFR level (model output)
- Subconstruct scores:
  - Fluency
  - Pronunciation
  - Grammar
  - Coherence
  - etc.

## PROCESS:
1. Identify gap skills
2. Map ke learning path level
3. Select relevant tasks
4. Generate practice recommendation

## OUTPUT:
- Target level berikutnya
- Skill yang perlu diperbaiki
- Latihan spesifik

---

# EXAMPLE (AI OUTPUT)

Input:
- CEFR: B1
- Weak: Coherence, Pronunciation

Output:
- Focus: B1 → B2 transition
- Learning Path:
  - Practice structured speaking
  - Use linking words
  - Do pronunciation shadowing

---

# DESIGN PRINCIPLES (DARI CEFR CASE STUDY)

- Fokus pada "Can Do", bukan grammar dulu
- Grammar = support task, bukan tujuan utama
- Learning harus:
  - modular (per minggu/bulan)
  - measurable
  - task-oriented
- Maksimal 10–20 objectives per level (biar usable)
